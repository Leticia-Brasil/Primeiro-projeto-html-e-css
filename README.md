# 🌐 Meu Primeiro Site — HTML e CSS

Este projeto foi desenvolvido durante um curso introdutório do Senac de **HTML e CSS**, sendo um dos meus primeiros contatos práticos com desenvolvimento Front-End web.

O objetivo foi colocar em prática conceitos básicos de estruturação de páginas, estilização e organização de elementos utilizando HTML e CSS.

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3

## 📚 Conceitos praticados

Durante o desenvolvimento, foram aplicados conhecimentos básicos de:

* Estruturação de páginas com HTML
* Utilização de títulos, textos, imagens e links
* Criação e organização de elementos
* Seletores e propriedades CSS
* Cores, fontes e espaçamentos
* Margens e preenchimentos
* Organização e estilização da página
* Noções básicas de layout e responsividade

## 🎯 Objetivo do projeto

Este projeto faz parte da minha jornada de aprendizado em desenvolvimento de software e representa uma das minhas primeiras experiências criando uma página web do zero.

Apesar de ser um projeto introdutório, ele foi importante para compreender na prática como **HTML e CSS trabalham juntos na construção de uma interface web**.

Pretendo continuar aprimorando meus conhecimentos em desenvolvimento web, estudando novas tecnologias e aplicando os conceitos aprendidos em projetos cada vez mais completos.
